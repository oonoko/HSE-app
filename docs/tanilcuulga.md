# HSE Safety — Ханбогд Хурд

Жолооч нарын аюулгүй ажиллагааны мэдлэгийг өдөр бүр шалгаж, сэргээж, хөгжлийг нь хянадаг вэб систем. Утсан дээр апп шиг суулгаж ашиглана (PWA), мэдэгдэл хүлээн авна.

## Хэн юу хийдэг вэ

| Хэрэглэгч | Боломж |
|---|---|
| **Жолооч** | SAP дугаараар нэвтэрнэ. Өдрийн асуумж өгнө, сургалтын дараах шалгалт өгнө, мэдлэг сэргээх тоглоом тоглоно, онооны самбар болон өөрийн хөгжлийн тайланг харна. |
| **Зочин** | SAP дугаар нь бүртгэлгүй хүн овог, нэрээ өгөөд зочноор нэвтэрнэ. Албан ёсны статистикт орохгүй. |
| **HSE админ (ээлжийн)** | Өөрийн ээлжийн асуумж үүсгэж, үр дүн, хөгжлийн тайланг харна, хариу засна, Excel татна. |
| **Ерөнхий админ** | Бүх ээлж, тоглоом, ажилтан (SAP, ээлж, CSV импорт)-ыг удирдана. |

Ээлж: 1, 2, 3, 4 болон «Хот». Админ PIN кодоор нэмэлт баталгаажуулалттай.

## Үндсэн боломжууд

- **Өдрийн асуумж** — товлосон өдөр, цагийн хооронд нээгдэнэ. Асуулт бүрт хугацаатай (30/45/60 сек). Асуултыг **асуултын сангаас** сонгож эсвэл санамсаргүй авч болно.
- **Сургалтын дараах шалгалт** — сургалтад суусан хүмүүсийн ирцийг бүртгээд шалгалт нээнэ. Тэнцэх хувь, оролдлогын тоог тохируулна. Тэнцээгүй хүн дахин өгнө, оролдлого дуусвал «ахин сургалтад суу» гэж түгжигдэнэ. Админ алдсан хариултыг шалтгаантай нь засч тэнцүүлж болно.
- **Мэдлэг сэргээх тоглоом** — үнэн/худал, дүрэм тааруулах, random box, кроссворд. Олон даалгавартай сангаас тоглох бүрт санамсаргүй N даалгавар гарна.
- **Онооны самбар** — өнөөдөр / энэ сар, ээлжээр шүүнэ.
- **Хөгжлийн тайлан** — хүн бүрийн асуумж, тоглоомын өөрчлөлт, сэдвээр хувь, алдсан асуултууд. Админ Excel / PDF татна, жолооч өөрөө харна.
- **Админы тайлан** — өдрийн dashboard, ээлжийн харьцуулалт, шалгалтын үр дүн (тэнцсэн нэрс, хариулт бүр, диаграмтай Excel), тоглоомын шинжилгээ, ээлжийн нэгдсэн Excel.
- **Мэдэгдэл** — асуумж нээгдэхэд өгөөгүй хүмүүст push сануулга очно.

## Онооны хуваарилалт

### 1. Өдрийн асуумж
Зөв хариулт бүр **50–100 оноо**:

> оноо = 50 + (үлдсэн хугацаа ÷ нийт хугацаа) × 50

Хурдан хариулах тусам их оноо авна. Буруу эсвэл хугацаа дууссан хариулт **0 оноо**. Нэг асуултын дээд оноо 100, асуумжийн дээд оноо = асуултын тоо × 100.

### 2. Сургалтын дараах шалгалт
- Оноо бодох арга өдрийн асуумжтай ижил (50–100 / зөв хариулт).
- **Тэнцсэн оролдлогын** оноо л нэмэгдэнэ. **Тэнцээгүй оролдлого 0 оноо** өгнө.
- Тэнцэх хувь: зөв хариултын тоо ÷ асуултын тоо (анхдагч 80%). Оролдлого: анхдагч 3.
- Админ хариуг «зөв» болгосон бол тэр асуулт **50 оноо** авна, «буруу» болгосон бол 0. Оноо болон тэнцсэн эсэх автоматаар дахин бодогдоно.
- Нэг шалгалтад нэг жолооч нэг үр дүнтэй тооцогдоно: тэнцсэн оролдлого, эс бөгөөс хамгийн өндөр оноотой оролдлого.

### 3. Мэдлэг сэргээх тоглоом
- Зөв хариулт (эсвэл зөв таасан үг) бүр **3 оноо**. Буруу бол 0.
- Хугацаа, хурдны нэмэгдэл байхгүй. Хязгааргүй дахин тоглож болно.
- Нэг тоглолтын дээд оноо = тухайн удаа гарсан даалгаврын тоо × 3 (жишээ нь 15 даалгавар → 45 оноо).
- Тоглоомын оноо асуумжийнхаас олон дахин бага тул тоглоомоор асуумжийг гүйцэхгүй.

### 4. Нийт оноо ба самбар
- **Нийт оноо** = бүх асуумж, шалгалтын (тооцогдсон) оноо + бүх тоглоомын оноо.
- **Онооны самбар** сонгосон хугацаанд (өнөөдөр / энэ сар) авсан асуумж + тоглоомын онооны нийлбэрээр эрэмбэлнэ. Ижил оноотой бол нэрээр.
- Эрэмбэ нь **нийт** ба **ээлж доторх** гэж хоёр харагдана.
- Зочдын оноо албан ёсны эрэмбэ, тайлан, дундаж, «өгөөгүй» тоонд орохгүй.

### Харьцуулалт

| Үйлдэл | Нэг удаад авах оноо |
|---|---|
| Асуумжийн нэг зөв хариулт | 50–100 |
| 7 асуулттай асуумж (бүгд зөв, хурдан) | ~700 хүртэл |
| Тоглоомын нэг зөв хариулт | 3 |
| 15 даалгавартай тоглоом (бүгд зөв) | 45 |

> Оноог өөрчлөх бол: асуумжийн томьёо `src/lib/scoring.ts`, тоглоомын оноо `src/lib/game-sampling.ts` (`POINTS_PER_ITEM`).
